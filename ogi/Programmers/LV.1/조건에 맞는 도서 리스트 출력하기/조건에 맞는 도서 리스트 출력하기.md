# SQL 문법 정리

## 조건에 맞는 도서 리스트 출력하기

### 사용한 SQL

```sql
SELECT BOOK_ID, DATE_FORMAT(PUBLISHED_DATE, '%Y-%m-%d') AS PUBLISHED_DATE
FROM BOOK
WHERE CATEGORY = '인문'
    AND PUBLISHED_DATE BETWEEN '2021-01-01' AND '2021-12-31'
ORDER BY PUBLISHED_DATE;
```

### 문제 이해하기

이 문제는 도서 정보를 담고 있는 `BOOK` 테이블에서 2021년에 출판된 `인문` 카테고리의 도서를 조회하는 문제입니다.

조회해야 하는 컬럼은 도서 ID인 `BOOK_ID`와 출판일인 `PUBLISHED_DATE`입니다.

조건은 두 가지입니다.

1. `CATEGORY`가 `'인문'`이어야 합니다.
2. `PUBLISHED_DATE`가 2021년 1월 1일부터 2021년 12월 31일 사이여야 합니다.

또한 결과는 `PUBLISHED_DATE`를 기준으로 오름차순 정렬해야 합니다.

### 핵심 문법

#### 1. SELECT

```sql
SELECT BOOK_ID, DATE_FORMAT(PUBLISHED_DATE, '%Y-%m-%d') AS PUBLISHED_DATE
```

`SELECT`는 조회할 컬럼을 선택할 때 사용합니다.

이 문제에서는 `BOOK_ID`와 `PUBLISHED_DATE`를 출력해야 합니다.

`PUBLISHED_DATE`는 날짜 형식을 `YYYY-MM-DD` 형태로 맞춰 출력해야 하므로 `DATE_FORMAT()` 함수를 사용합니다.

#### 2. DATE_FORMAT()

```sql
DATE_FORMAT(PUBLISHED_DATE, '%Y-%m-%d')
```

`DATE_FORMAT()`은 날짜 데이터를 원하는 형식의 문자열로 변환할 때 사용하는 함수입니다.

`%Y`는 4자리 연도, `%m`은 2자리 월, `%d`는 2자리 일을 의미합니다.

따라서 `DATE_FORMAT(PUBLISHED_DATE, '%Y-%m-%d')`는 날짜를 `2021-01-01`과 같은 형태로 출력합니다.

#### 3. FROM

```sql
FROM BOOK
```

`FROM`은 데이터를 조회할 테이블을 지정할 때 사용합니다.

도서 정보는 `BOOK` 테이블에 들어 있으므로 `FROM BOOK`을 작성합니다.

#### 4. WHERE

```sql
WHERE CATEGORY = '인문'
    AND PUBLISHED_DATE BETWEEN '2021-01-01' AND '2021-12-31'
```

`WHERE`은 원하는 조건에 맞는 행만 조회할 때 사용합니다.

이 문제에서는 카테고리가 `인문`이고, 출판일이 2021년인 도서만 필요합니다.

두 조건을 모두 만족해야 하므로 `AND`로 연결합니다.

#### 5. BETWEEN

```sql
PUBLISHED_DATE BETWEEN '2021-01-01' AND '2021-12-31'
```

`BETWEEN A AND B`는 값이 A 이상 B 이하인 데이터를 찾을 때 사용합니다.

여기서는 `PUBLISHED_DATE`가 2021년 1월 1일부터 2021년 12월 31일까지인 도서를 조회합니다.

#### 6. ORDER BY

```sql
ORDER BY PUBLISHED_DATE;
```

`ORDER BY`는 조회 결과를 정렬할 때 사용합니다.

문제에서 출판일을 기준으로 오름차순 정렬하라고 했으므로 `ORDER BY PUBLISHED_DATE`를 작성합니다.

오름차순은 기본 정렬 방식이기 때문에 `ASC`를 생략할 수 있습니다.

### 실행 흐름

1. `BOOK` 테이블에서 데이터를 조회합니다.
2. `CATEGORY`가 `'인문'`인 도서만 남깁니다.
3. `PUBLISHED_DATE`가 2021년인 도서만 남깁니다.
4. `BOOK_ID`와 형식을 맞춘 `PUBLISHED_DATE`를 출력합니다.
5. 결과를 `PUBLISHED_DATE` 기준으로 오름차순 정렬합니다.

### 최종 정리

이 문제의 핵심은 `WHERE`로 카테고리와 출판일 조건을 걸고, `DATE_FORMAT()`으로 날짜 출력 형식을 맞춘 뒤 `ORDER BY`로 정렬하는 것입니다.

```sql
SELECT BOOK_ID, DATE_FORMAT(PUBLISHED_DATE, '%Y-%m-%d') AS PUBLISHED_DATE
FROM BOOK
WHERE CATEGORY = '인문'
    AND PUBLISHED_DATE BETWEEN '2021-01-01' AND '2021-12-31'
ORDER BY PUBLISHED_DATE;
```
